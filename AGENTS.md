## Tech Stack

The project must use the following stack:

- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: TailwindCSS
- Components: shadcn/ui
- Content: MDX
- Deployment: Vercel

Avoid unnecessary libraries. Keep the stack minimal and modern.
